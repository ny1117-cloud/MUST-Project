# 아이디어 메모: 영상 보조 중증도분류 + 자동 차팅 (2026.11.7, 책임자 발상)

## 아이디어
- 중증도분류는 사람이 하되, 영상(카메라·원격 영상진료)을 AI가 함께 보며 사람이 놓친 신호(외관·호흡 양상·의식·보행·피부색 등)를 보완 표시
- 영상진료가 끝나면 진료 기록(차팅)을 자동 생성

## CEU와의 관계
- CEU의 핵심 운영 요소인 "원격 응급의학 전문의 감독"의 실제 구현 수단. CEU 현장 인력(간호·응급구조)의 분류를 원격 의사와 AI가 함께 보완하는 구조
- 책임자의 AI 2026 과소분류(undertriage) 탐지 논문과 직접 연결: "사람이 놓치는 것"을 데이터로 이미 정의해 둠

## 이번 핵심연구(기초) 계획서와의 관계
- CDW에는 영상 자료가 없으므로 이번 과제 안에서 검증 불가. 이번 계획서에는 "후속 연구·활용" 항목에 한 줄로만 언급
- 성격상 개발·실증 과제(2027 2차 전략형, 보건의료기술 R&D, 범부처 의료기기)와 특허에 적합

## 특허 관점 (연 5건 목표와 연결)
- 후보 1: 영상 기반 분류 보조 — 사람 분류 결과와 영상 분석 결과의 불일치를 탐지해 재분류를 권고하는 시스템
- 후보 2: 원격 영상진료 세션에서 구조화 진료기록을 자동 생성하고 분류 근거를 함께 기록하는 방법
- 선행기술 조사 필요: 원격 triage AI, ambient clinical documentation(영상진료 자동 기록)은 이미 상용 제품이 있어 청구항을 "CEU 맥락의 분류 불일치 탐지"로 좁혀야 함

## 먼저 답할 질문 (책임자)
1. 이 아이디어로 가장 먼저 증명하고 싶은 것은 무엇인가 — (a) 영상이 사람의 과소분류를 줄인다, (b) 자동 차팅이 기록 시간을 줄이고 품질을 유지한다. 둘은 필요한 데이터와 평가 설계가 다르다
2. 영상 자료를 어디서 얻을 것인가 — 서울성모 응급실 분류 구역 촬영(IRB·동의 난이도 높음), 국제진료센터 원격진료 세션, 시뮬레이션 환자
