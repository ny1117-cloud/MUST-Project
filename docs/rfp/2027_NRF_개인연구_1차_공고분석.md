# 2027년도 과기정통부 기초연구사업(개인연구) 1차 신규과제 공고 분석

- 공고: 과학기술정보통신부 공고 제2026-1069호 (2026.11.5)
- 전문기관: 한국연구재단(NRF) 개인연구지원팀
- 공모방식: **자유공모** (RFP 없음 → 주제·목표를 우리가 정의해야 함)
- 신청: IRIS(https://www.iris.go.kr) 온라인
- **별첨(세부 신청요강·서식·평가항목 배점)은 2026.11.16.(월) NRF 홈페이지 공지 예정** → 이 문서는 공고문만으로 작성했으며, 배점·분량·대표실적 요건은 11.16 자료로 반드시 갱신해야 함
- 분석일: 2026.11.6 (접수 시작까지 19일, 핵심연구 마감까지 31일)

## 1. 한눈에 보는 결론

1. **이번 공고는 "어느 트랙에 넣느냐"가 당락의 절반이다.** 자유공모이므로 주제보다 먼저 자격·경쟁 구조로 트랙을 고른다.
2. 개인기초는 **1인 1과제**. 현재 과기부·교육부 소관 개인기초 과제를 연구책임자로 수행 중이고 그 과제가 2027.12.31 이후에 끝나면 1차 신청 자체가 불가(한우물파기 예외).
3. 신진 자격(박사 7년 이내 / 만 39세 이하 / 최초 조교수 임용 5년 이내)에 해당하면 **신진연구 유형B(1.5억, 460개)** 가 최우선. 해당하지 않으면 **핵심연구 유형A(1억, 825개) 또는 유형B(2억, 670개)**.
4. 핵심 유형A·B, 신진 A·B는 **온라인 서면평가 단독** → 발표 없이 계획서만으로 결정. 문서 완성도가 전부다.
5. 1차에서 떨어지면 **2027.3월 2차 공모(기본연구A·B 합계 1,950개)** 가 안전망. 단, 1차 선정 시 2차 신청 불가이고, 교육부 지역중심혁신지원·학술연구인재육성 신청자는 2차 신청 불가.
6. 핵심연구 마감 **2026.12.7.(월) 18:00** (연구자) / **12.9.(수) 18:00** (기관승인). 나머지 트랙은 12.8 / 12.10. "작성중" 상태로 마감되면 미접수.

## 3. 트랙 선택 의사결정 (가장 먼저 답해야 할 질문)

### Q1. 지금 연구책임자로 수행 중인 개인기초 과제(과기부 우수연구 / 교육부 통합기초·지역중심혁신·학술연구인재육성)가 있는가?
- **있고 2027.12.31 이후 종료** → 1차 신청 불가. 예외는 한우물파기(박사 15년 이내)뿐이며, 선정 시 기존 과제를 2027.12.31자로 종료해야 함.
- **있지만 2027.12.31 이내 최종종료(연차종료 제외)** → 신청 가능.
- **없음** → 아래로.

### Q2. 신진 자격에 해당하는가? (하나라도 해당하면 신진)
- 박사학위 취득 후 7년 이내, 또는
- 만 39세 이하, 또는
- 최초 조교수 이상 임용 후 5년 이내인 국내대학 전임교원
→ 해당 시 **신진연구 유형B(1.5억)** 를 1순위. 유형A(1억)는 선정 수는 많지만(600개) 기간이 3년으로 짧음.
→ 소속이 지역대학이면 **지역장기연구(10년, 1년차 3억)** 도 검토. 단 토론평가.

### Q3. 신진 자격이 없으면: 핵심 유형A vs 유형B vs 유형C vs 한우물파기
| 기준 | 유형A (1억) | 유형B (2억) | 유형C (3억) | 한우물파기 (2억×10년) |
|---|---|---|---|---|
| 선정 수 | 825 | 670 | 100 | 40 |
| 평가 | 서면 | 서면 | 토론 | 토론 |
| 요구 역량 | 안정적 실적 | 상위 실적 | 리더급 실적 | 박사 15년 이내 + 한 분야 장기 비전 |
| "무조건 따야 함"에 대한 적합도 | ◎ | ○ | △ | △ (자격 되면 도전 가치 큼, 단 선정 시 기존 과제 정리 필요) |

- 리더연구와 핵심연구(C/B/A/도약 중 1개)는 **중복 신청 가능**하지만, 그 외는 1차 내 1과제만 신청.
- **권고:** 실적이 2억 트랙 평균을 분명히 넘는다는 확신이 없으면 **유형A**. 유형A 선정 후에는 당해연도 2차 신청이 막히지만, 1억 과제를 확보하는 것이 목표라면 문제없음. 유형B는 "연구비 규모가 커야 하는 이유(데이터 구축·장비·인력)"가 계획서에서 설득돼야 함.

### Q4. 2차(기본연구)까지 2단 구조로 갈 것인가?
- 1차 핵심 유형A 신청 → 미선정 시 2027.3월 기본연구B(0.7억, 1,200개)로 재도전. 선정률이 가장 높은 트랙.
- 1차 계획서를 2차 양식으로 재활용 가능하므로, 1차 계획서를 "본체"로 만들고 2차는 축약본으로 간다.

## 5. 평가 대응 전략

### 5-1. 서면평가 단독 트랙의 의미
핵심 A/B, 신진 A/B는 발표·토론 없이 **계획서 1부로 끝**난다. 따라서:
- 첫 2쪽(요약·필요성·목표)에서 "무엇을, 왜, 어떻게, 얼마나"가 한 번에 읽혀야 한다. 심사위원은 수십 건을 읽는다.
- 그림 1장으로 연구 개념(입력 데이터 → 방법 → 산출물 → 검증)을 보여줘라.
- 연차별 정량목표(논문 N편·IF 수준, 모델 성능지표, 데이터셋 규모, 특허 N건)를 표로 고정하라.

### 5-2. 기초연구 심사의 암묵적 기준 (정확한 배점은 11.16 신청요강으로 확정)
NRF 개인기초 서면평가는 관례적으로 다음 축으로 채점돼 왔다.
1. **연구의 창의성·도전성** — "응용·개발"이 아니라 기초 질문이어야 함. 응급의학 ML이라면 "예측 성능 향상"보다 "응급 환자 데이터의 비정상성(non-stationarity)·분포 이동 하에서의 예측 불확실성의 이론적 한계와 정량화" 같은 과학적 질문으로 프레이밍.
2. **연구목표·내용·방법의 구체성과 타당성** — 데이터 확보 근거(IRB, 데이터 규모, 접근권), 분석 파이프라인, 검증 설계(외부검증·전향적 검증).
3. **연구자 역량(대표연구실적)** — 과제 주제와 직결된 실적 중심. "논문 N편"보다 "주제 적합 논문 5편 + 그 논문이 이번 과제의 어느 가설을 뒷받침하는지" 서술.
4. **기대효과·활용** — 기초연구이므로 학술적 파급을 앞에, 임상·산업 파급을 뒤에.

### 5-3. 이 책임자(응급의학 + 국제진료 + ML/QML) 관점의 포지셔닝 포인트
- **분야(CRB) 선택이 중요하다.** 의약학 분과에 넣으면 임상적 타당성·데이터 품질을 보고, ICT·융합 분과에 넣으면 알고리즘 신규성을 본다. 대표실적이 임상 논문 위주면 의약학 분과가 유리. 11.16 요강의 분야 분류표 확인 후 결정.
- **"양자 ML"은 기초연구 프레임에 잘 맞는 카드**이지만, 실행 가능성(시뮬레이터·클라우드 QPU 접근, 소규모 데이터셋에서의 비교 실험 설계)을 구체적으로 써야 "유행어"로 감점되지 않는다. 고전 ML 베이스라인 대비 어떤 조건에서 이득이 생기는지를 **가설 형태**로 적는 것이 안전.
- **데이터 우위**를 증거로 제시: 국제진료센터·응급실 데이터의 규모, 기간, 변수 수, 이미 확보된 IRB 승인 여부. 서면평가에서 "데이터가 실제로 있는가"는 가장 흔한 감점 포인트.
- 부실학술지 게재 실적은 평가에 불리하게 반영될 수 있음(공고 8장). 대표실적 선정 시 제외.
- AI 도구 사용 내역 표기는 "권장" 사항. 표기 시 회사·연도·도구명·버전·자료유형·URL·활용방법 형식. 계획서 전문을 외부 AI에 업로드했을 때 정보 유출 책임은 연구자에게 있음.
